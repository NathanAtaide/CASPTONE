# Packages installed in the isolated forecasting virtualenv (/opt/ml-venv).
# The forecasting DAGs (ml_forecast_selection, ml_forecast_next_month) call
# /opt/ml-venv/bin/python -m lakehouse.forecasting ... through BashOperator, the
# same way dbt is called from /opt/dbt-venv. Keeping these libraries out of the
# Airflow environment means torch/scikit-learn/xgboost/mlflow can never break
# Airflow's own dependencies.
#
# Versions follow the notebooks of the ML/DL studies (ml_models/) so the
# pipeline reproduces their numbers, and the MLflow client follows the server.
